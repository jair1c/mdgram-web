Instalación

Instalarlo toma menos de un minuto

  1. Descarga el APK

    Elige la versión UNIVERSAL si no sabes qué arquitectura usa tu teléfono. Funciona en todos.

  2. Permite la instalación

    En Ajustes → Seguridad, autoriza a tu navegador o gestor de archivos a instalar apps desconocidas.

  3. Abre el archivo

    Toca el APK descargado y confirma la instalación. No necesitas desinstalar Telegram oficial.

  4. Inicia sesión

    Entra con tu número de teléfono habitual. Tus chats y grupos aparecen tal cual los dejaste.

Preguntas frecuentes

Dudas habituales

¿MDGram es una aplicación oficial de Telegram?
No. MDGram es un cliente no oficial desarrollado de forma independiente sobre la API pública de Telegram. No está afiliado a Telegram Messenger LLP ni respaldado por ellos.
¿Mi cuenta está segura?
MDGram se conecta a los servidores de Telegram usando su API oficial, con el mismo cifrado del protocolo MTProto. Aun así, al tratarse de un cliente de terceros, la instalación queda bajo tu responsabilidad: descarga siempre desde esta web o desde el repositorio oficial del proyecto.
¿Está disponible para iPhone?
No. MDGram es exclusivo de Android y requiere la versión 5.0 o superior. El «estilo iOS» al que se hace referencia es un tema visual dentro de la app, no una versión para iOS.
¿Puedo tenerlo junto a Telegram oficial?
Sí. Ambas apps pueden convivir en el mismo teléfono y usar la misma cuenta o cuentas distintas.
¿Qué arquitectura debo descargar?
Si tienes dudas, usa la versión UNIVERSAL: detecta automáticamente la arquitectura de tu dispositivo. Las variantes Armv7a y Arm64 son más ligeras, pero solo si sabes cuál corresponde a tu teléfono.
¿Tiene coste o publicidad?
MDGram es gratuito y no incluye suscripciones. No se cobra por ninguna de sus funciones.

¿Listo para probarlo?

Descarga MDGram y estrena tu Telegram en menos de un minuto. Gratis, sin registro y sin publicidad.
